Raspberry Pi 3 Model B+

One board.
One clear purpose.

The Raspberry Pi 3 Model B+ is a 1.4GHz 64-bit quad-core single-board computer with 1GB LPDDR2 memory, dual-band Wi-Fi, Bluetooth 4.2, four USB 2.0 ports, full-size HDMI and microSD storage.

The processor inside

BCM2837B0.
1.4GHz.

The Raspberry Pi documentation identifies the BCM2837B0 as the Broadcom SoC used in Raspberry Pi 3 Model B+. Its ARM cores are capable of 1.4GHz and the VideoCore IV GPU runs at 400MHz.

Broadcom BCM2837B04 × Cortex-A53ARMv8 64-bitVideoCore IV
